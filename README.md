## 什么是 KiwiVM 一键安装

KiwiVM 是搬瓦工自己开发的 VPS 管理面板。它最好用的一点，就是重装系统不用你自己挂 ISO 镜像，不用敲命令，直接在后台点几下就完成了。

支持的系统包括 Ubuntu、Debian、CentOS 系列，最新已经跟进到 Ubuntu 24.04 LTS 和 Ubuntu 26.04，Debian 13 也已上线。整个重装过程快的话一两分钟，慢的话不超过五分钟，完全在可接受范围内。

重装完成后，系统会自动生成一个新的 root 密码和一个随机 SSH 端口——注意，搬瓦工的 SSH 端口不是默认的 22，每次重装都会变，记得保存好。

## 重装前必须做的事

这一步跳过的人，事后哭都来不及。

**备份数据。** 重装意味着 VPS 上的所有内容清零：网站文件、数据库、配置、日志，一次性全没。KiwiVM 后台有免费的快照（Snapshot）和自动备份（Backups）功能，建议在动手前先创建一个快照。这个操作免费，出了问题可以从快照恢复，省心很多。

备份这件事就是"没出事前觉得多余，出了事才知道值钱"，不废话了。

## 搬瓦工一键安装系统：完整步骤

### 第一步：登录 KiwiVM 控制面板

进入搬瓦工官网，右上角点「Client Area」登录账号。

登录后依次点：**Services → My Services**，找到你买的那台 VPS，点右侧的「**KiwiVM Control Panel**」按钮，进入面板。

### 第二步：关闭 VPS

进入 KiwiVM 后台后，首先看到的是「Main Controls」主界面，这里显示 IP、SSH 端口、内存、硬盘、流量等信息。

如果你的 VPS 状态是「Running」，先点「**Stop**」按钮关机。等几秒钟，状态变成「Stopped」再继续。

不关机直接重装会失败。

### 第三步：进入 Install new OS

左侧菜单往下拉，找到「**Install new OS**」，点进去。

页面会显示一个系统列表的下拉框。选你想装的系统版本，然后勾选下方的同意条款：

> I agree that all data on my VPS will be lost.

勾完后，点「**Reload**」按钮，确认安装开始。

### 第四步：等待完成，保存新密码

重装一般 1-5 分钟完成。完成后，页面上会显示新的：

- **root 密码**
- **SSH 端口号**（不是 22，是随机数字）

这两个信息同时也会发送到你注册时用的邮箱。不管哪个，都记下来，后面 SSH 连接要用。

### 第五步：用 SSH 工具登录验证

用 Xshell、FinalShell、Termius 或系统自带终端，输入 IP 地址、刚拿到的端口号和 root 密码，连接成功就说明一切正常了。

## 选哪个系统？

说实话这个问题没有唯一答案，但可以给个参考框架：

**建站（WordPress、Typecho 等）**：Debian 12 或 Ubuntu 22.04/24.04，两者对主流面板（宝塔、1Panel）兼容都好，Debian 占用更低，Ubuntu 社区资料更多。

**学 Linux / 跑脚本**：Ubuntu 24.04 LTS 是目前最合适的选择。内核版本新，BBR 内置，资料丰富，出了问题好查。

**部署 AI 应用（Dify、n8n、FastGPT 等）**：Ubuntu 24.04，Python 和库的兼容性更好，省去大量环境配置。

**CentOS**：新手不建议，CentOS 7 已经停止维护，CentOS Stream 又比较特殊，坑比较多。

顺便提一句：Ubuntu 24.04 重装后，老版 SSH 客户端可能因为加密算法变更连不上，记得把本地 SSH 工具也更新一下。

## 重装系统之后通常要做这几件事

装完系统不是终点，还有几步要走：

1. **更新系统**：`apt update && apt upgrade -y`（Ubuntu/Debian）
2. **开启 BBR 加速**：Ubuntu 24.04 内核已内置，确认开启可以优化网络吞吐
3. **修改 SSH 端口**（可选）：默认随机端口已经比 22 安全一些，进一步修改可选
4. **安装面板或环境**：建站的装宝塔或 1Panel，跑 AI 应用的按对应文档走
5. **设置自动备份**：KiwiVM 里顺手开一下，后悔药备着

## 几个搬瓦工一键安装的常见问题

**Q：重装系统需要多少次可以随便重装吗？**

可以，没有次数限制。但每次重装都会清空所有数据，操作前务必备份。

**Q：重装后 SSH 连不上？**

最常见的原因是端口写错了。搬瓦工每次重装都会重新生成随机端口，不是 22，要从 KiwiVM 面板或邮件里确认新端口。另一种情况是 Ubuntu 24.04 的 OpenSSH 默认禁用了一些旧加密算法，本地客户端版本过低时会报错，更新一下客户端工具就好。

**Q：忘记记 root 密码怎么办？**

不用重装系统，KiwiVM 左侧菜单里有「Root password modification」功能，先停机，再点「Generate and set new root password」，新密码会发到邮箱。

**Q：重装系统会换 IP 吗？**

不会。重装系统保留原 IP 地址。换机房才会换 IP（机房迁移功能同样在 KiwiVM 里操作）。

**Q：安装 Windows 系统可以吗？**

KiwiVM 的「Install new OS」列表只包含 Linux 发行版。要装 Windows 需要通过挂载自定义 ISO 的方式操作，流程更复杂，不是入门用户的第一选择。
